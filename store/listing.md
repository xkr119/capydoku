# 스토어 등록정보

Play Console에 **그대로 복사해 붙이면 되는** 확정 문구다.
글자 수는 모두 Play 상한 안에서 세어 두었다.

> ⚠️ 건강 효능 문구 금지 — "치매 예방", "인지 능력 향상", "두뇌 나이" 같은
> 표현은 의학적 주장으로 분류되어 반려 사유가 된다.
> 대신 "집중", "차분하게", "머리 식히기" 같은 **경험** 표현만 쓴다.

## 한국어 — `ko-KR` (기본 언어)

### 앱 이름 (최대 30자) — 17자
```
카피도쿠 : 카피바라 논리 퍼즐
```

> **`Capydoku`(라틴)가 아니라 `카피도쿠`(한글)다.** 한국 사용자는 한글로
> 검색한다. 라틴 표기는 영어 목록이 따로 가져간다.
>
> **"카피바라"를 반드시 남긴다.** "논리 퍼즐"은 경쟁이 심해 신생 앱이 뚫기
> 어렵지만 **"카피바라 게임"은 경쟁이 거의 없다.** 작은 앱은 넓고 붐비는
> 키워드보다 **좁고 확실한 키워드에서 1등** 하는 편이 훨씬 낫다.
>
> **"퀸즈"는 넣지 않는다.** ① 저들의 *이름*이라 이 프로젝트의 원칙에 어긋나고
> ② 다른 앱 브랜드를 제목에 넣는 것은 Play 반려 사유가 될 수 있고
> ③ "퀸즈"로 검색하는 사람은 **그 앱을 찾는 중**이라 봐도 그냥 나간다 —
> 노출만 늘고 설치가 안 되면 Play가 매기는 지표가 오히려 나빠진다.
>
> **"스도쿠"도 제목에는 넣지 않는다.** 검색량은 크지만 이건 스도쿠가 아니다.
> "스도쿠인 줄 알았는데"라는 별점 1점이 온다. 자세한 설명에서 **비교로만** 쓴다.

### 간단한 설명 (최대 80자) — 44자
```

```

> 제목이 30자라 못 담은 키워드를 여기서 메운다 —
> `논리`·`카피바라`·`퍼즐`·`당근`·`오프라인`·`두뇌 게임`이 한 줄에 다 들어간다.

## English — `en-US`

> Play에는 그냥 `en`이 없다. `en-US`가 나머지 영어권(`en-GB`·`en-AU`…)의
> **대체**라 하나만 넣을 거면 이것이다.

### App name (max 30) — 25자
```
Capydoku: Capybara Puzzle
```

> `Capydoku: Capybara Logic Puzzle`은 **31자로 한 자 넘는다.** 그래서 하나를
> 버려야 하는데, 위와 같은 이유로 `Logic`을 버리고 `Capybara`를 남겼다
> (`Capydoku`의 `-doku`가 이미 퍼즐이라는 신호이기도 하다).

### Short description (max 80) — 75자
```
One capybara per row, column, and region. Pure logic, no guessing. Offline.
```

## 검색에 대해 (다음에 문구를 고칠 때)

- **첫 두 줄이 제일 중요하다.** "더보기"를 누르기 전에 보이는 부분이고,
  Play도 앞쪽에 가중치를 둔다. 핵심 키워드를 거기 넣는다.
- 키워드는 **자연스럽게 서너 번** 반복한다. 나열하면 키워드 스터핑이라
  정책 위반이고, 무엇보다 사람이 안 읽는다.
- **건강 효능 문구 금지** — "치매 예방", "인지 능력 향상", "두뇌 나이"는
  의학적 주장으로 분류되어 반려 사유다. "집중", "머리 식히기" 같은
  **경험** 표현만 쓴다.
- 제목에 `무료`·`최고`·`1위`·`할인` 같은 판촉 문구를 넣으면 반려된다.
- 문구를 고쳐도 색인에 반영되기까지 며칠 걸린다. 하루 만에 판단하지 말 것.

## 출시명 · 출시 노트

### 출시명 (Release name) — 사용자에게 안 보인다

Play Console이 버전으로 자동 채워 준다(`1 (1.0.0)`). 그대로 둬도 되지만,
나중에 목록에서 알아보기 쉽게 적어 두는 편이 낫다.

```
1.0.0 (1) · 첫 폐쇄 테스트
```

**재업로드할 때마다 `pubspec.yaml`의 `version: 1.0.0+1`에서 `+` 뒤 숫자를
올려야 한다** — 같은 빌드 번호는 Play가 거부한다. 출시명도 같이 고칠 것.

### 출시 노트 (What's new) — 언어마다 따로, 각 500자

첫 버전이라 "고쳤습니다"가 아니라 **무엇을 파는 앱인지**를 적는다.
목록 설명을 이미 읽고 들어온 사람이 보는 자리라 짧게 간다.

**한국어 (182자)**
