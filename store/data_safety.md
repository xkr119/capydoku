# Play Console — 데이터 안전(Data safety) 설문 답안

Play Console → 정책 → 앱 콘텐츠 → 데이터 안전.
**틀리게 답하면 정책 위반이다** — 앱이 실제로 하는 일과 답이 어긋나면
심사에서 걸리거나, 통과했더라도 나중에 내려간다.

핵심: **개발자는 아무것도 수집하지 않지만, AdMob SDK는 수집한다.**
"내가 안 봤으니 수집이 아니다"는 통하지 않는다 — 앱이 제3자에게 보내면
그건 공유(shared)로 신고해야 한다.

---

## 개요 질문

| 질문 | 답 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **예** |
| 전송 중 데이터가 암호화되나요? | **예** (AdMob은 HTTPS) |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** — 앱 삭제 시 기기 데이터 전부 삭제, 광고 ID는 Android 설정에서 초기화 가능 |

---

## 수집·공유하는 데이터 유형

### 기기 또는 기타 ID → 기기 또는 기타 ID

| 항목 | 답 |
|---|---|
| 수집됨 | 예 |
| 공유됨 | **예** (Google AdMob) |
| 처리 방식 | 일시적으로만 처리? → **아니오** |
| 필수/선택 | 필수 |
| 목적 | **광고 또는 마케팅** |

> Android 광고 ID다. AdMob을 쓰면 무조건 여기에 체크가 들어간다.

### 앱 활동 → 앱 상호작용

| 항목 | 답 |
|---|---|
| 수집됨 | 예 |
| 공유됨 | **예** (Google AdMob) |
| 필수/선택 | 필수 |
| 목적 | **광고 또는 마케팅** |

> 광고 노출·클릭 기록. 게임 플레이 기록은 기기 밖으로 나가지 않으므로
> 여기에 해당하지 않는다.

### 앱 정보 및 실적 → 기타 앱 실적 데이터

AdMob은 기본적으로 진단 정보를 보낼 수 있다. 보수적으로 **예**로 신고한다.

| 항목 | 답 |
|---|---|
| 수집됨 | 예 |
| 공유됨 | 예 (Google) |
| 필수/선택 | 필수 |
| 목적 | **분석** |

## 체크하지 **않는** 항목 (앱이 실제로 안 하므로)

- 위치 (대략적/정확한 위치 모두)
- 개인 정보 (이름·이메일·주소·전화번호·인종·성적 지향 등 전부)
- 금융 정보
- 건강 및 피트니스
- 메시지
- 사진 및 동영상
- 오디오 파일
- 파일 및 문서
- 캘린더
- 연락처
- 검색 기록
- 설치된 앱 목록

---

## 광고 ID 선언 (별도 질문)

Play Console은 "앱이 광고 ID를 사용합니까?"를 따로 묻는다 → **예**.
`com.google.android.gms.permission.AD_ID` 권한은 google_mobile_ads 플러그인이
자동으로 병합해 넣으므로 매니페스트에 직접 쓸 필요가 없다.
